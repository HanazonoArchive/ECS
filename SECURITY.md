# Security Policy

## Reporting Security Vulnerabilities

This is an **archived project** maintained for portfolio and reference purposes.

If you discover a security vulnerability in this codebase:

1. **Do not** create a public GitHub issue
2. Please contact the maintainer directly
3. Allow time for response and assessment

Since this is an archived project, security updates are not actively maintained. For production use, consider forking and maintaining your own version.

## Scope

Security advisories apply to:
- Source code in this repository
- Released distributions

## Out of Scope

- Deprecated or unsupported features
- Theoretical vulnerabilities without practical impact
- Social engineering or phishing attacks

**Status:** This project is archived and not actively maintained.
