# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.3.0] - 2024

### Added
- Improved version of Energy System Calculator
- Custom undecorated window with drag functionality
- Input validation for numeric fields only
- Support for multiple games (Honkai: Starrail, Zenless Zone Zero, and others)

### Features
- Calculate energy regeneration time
- Real-time date and time display
- Hour:Minute:Second duration calculation
- Status feedback system
